 Currency Converter (Java)

 Description
A simple Java-based currency converter that uses a static method to convert between currencies using predefined exchange rates.

Features
- Converts USD, INR, EUR
- Uses static method
- Takes user input
- Displays result

 How to Run
1. Compile:
   javac CurrencyConverter.java

2. Run:
   java CurrencyConverter

 Sample Input
USD → INR, Amount = 10

 Output
830.0 INR
